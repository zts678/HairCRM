# 美发店会员管理系统

基于 Flask + SQLite 的轻量级美发店会员管理系统，支持会员管理、充值消费、套餐、理发师计件、业绩统计、收费交款、多操作员权限管理等功能。

## 功能特性

- **会员管理**：会员新增/编辑/搜索、挂失/恢复/注销（注销自动退还充值本金）
- **充值**：支持赠送金额（充值本金 + 赠送金分开记账）、多种支付方式、记录撤销
- **消费**：服务项目选择、会员等级折扣、**扣费优先扣本金后扣赠送金**、服务理发师计件、记录撤销
- **套餐管理**：为会员添加次卡套餐并核销
- **交易记录**：充值/消费明细查询、按会员筛选、记录撤销
- **多操作员**：登录账号独立管理，**仅 admin 可管理操作员**，支持修改自己密码
- **理发师管理**：理发师档案维护
- **收费交款**：选择充值操作员自动统计其当日收到充值金额，生成交款单，支持撤销
- **业绩报表**：按日期范围统计每位理发师的消费笔数、原价、实收
- **操作日志**：记录系统内关键操作
- **系统设置**：店铺名称、会员等级折扣、服务项目列表、功能入口
- **数据备份**：一键备份 SQLite 数据库

## 技术栈

- Python 3 + Flask
- SQLite（内置数据库，自动建表迁移）
- Jinja2 模板 + 原生 HTML/CSS/JS
- FontAwesome 图标

## 快速开始

1. 安装依赖

```bash
pip install flask
```

2. 启动服务

```bash
python app.py
```

3. 浏览器访问

```
http://127.0.0.1:5000
```

4. 默认账号

```
管理员：admin / 123456
```

> 首次登录后建议立即修改密码。登录后可在"系统设置 → 功能菜单 → 操作员管理"中添加操作员账号。

## 核心业务说明

- **余额结构**：会员余额 = 充值本金 + 赠送金。消费时优先扣充值本金，本金扣完再扣赠送金；注销时只退还充值本金，赠送金作废。
- **交款流程**：在"收费交款"页选择充值操作员和日期，系统自动汇总其当日收到的充值金额（按现金/微信/支付宝/银行卡），确认后生成交款单，同一操作员同一日期不可重复交款。
- **权限**：操作员管理、数据备份等敏感功能仅 admin 可用；普通操作员登录后只能操作日常业务并查看自己的交款记录。
- **撤销**：充值、消费、交款记录均支持撤销，撤销后余额/交款状态自动回滚。

## 数据备份

侧边栏底部"数据备份"按钮可将数据库复制到 `backups/` 目录，文件名为 `backup_时间戳.db`，可手动恢复。
